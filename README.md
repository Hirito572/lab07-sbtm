## Зорилго

Уншлагын жагсаалт вэб аппликейшний чанарыг Session-Based Test Management (SBTM) аргаар шалгаж, тестийн charter, session report болон илэрсэн согогийн тайлангуудыг боловсруулах.

## Файлын бүтэц

- `README.md` — төслийн мэдээлэл болон тестийн дүгнэлт
- `charter.md` — тестийн зорилго, сонгосон аяллууд
- `session-report.md` — тестийн session тэмдэглэл
- `bugs/` — согогийн тайлангууд
- `screenshots/` — UI согогийн screenshot
- `evidence/` — API тестийн нотолгоо
- `.gitignore` — Git-д оруулахгүй файлууд

## Тестийн хамрах хүрээ

- Хоосон болон дутуу талбартай ном нэмэх
- Номын оны хязгаарыг шалгах
- Ижил номыг давхардуулан нэмэх
- Номын жагсаалт болон үйлдлийн мессежийг шалгах

## Сонгосон аяллууд

- **Couch Potato:** хоосон болон дутуу оролтыг шалгах
- **Boundary Testing:** оны хязгаарын утгуудыг шалгах
- **Fed-Ex:** өгөгдөл нэмэх болон давхардлын нөхцөлийг шалгах
- **Supermodel:** интерфэйсийн харагдах байдлыг шалгах
- **Saboteur:** API түвшний буруу оролтыг шалгах

## Илэрсэн согогууд

| ID | Согог | Ноцтой байдал |
|---|---|---|
| BUG-01 | Бүх талбар хоосон байхад ном нэмэгдсэн | Major |
| BUG-02 | 999 онтой ном нэмэгдсэн | Major |
| BUG-03 | Ижил номыг давхардуулан нэмэх боломжтой | Major |

## Дүгнэлт

Exploratory тестээр хоосон талбартай ном нэмэгдэх, зөвшөөрөгдөх хязгаараас бага онтой ном нэмэгдэх, ижил ном давхардах гэсэн гурван согог ажиглагдсан. BUG-01 нь заавал бөглөх талбарын шалгалт хангалтгүй байгааг харуулсан. BUG-02 нь оны хязгаарын шалгалт ажиллахгүй байгааг харуулсан. BUG-03 нь ижил гарчиг, зохиолчтой номыг давхардуулан бүртгэх боломжтойг харуулсан. Эдгээр тохиолдлыг тус тусад нь алдааны тайланд баримтжуулсан. Талбарын шалгалт, оны хязгаар болон давхардлын нөхцөлийг автомат тестээр шалгаж болно. Интерфэйсийн харагдах байдал болон мессежийн ойлгомжтой байдлыг гараар шалгах нь мөн чухал. API түвшний шалгалтын үр дүнг `evidence/` хавтсанд бодит нотолгоогоор баримтжуулна.

## Тестийн материал

Тестийн дэлгэрэнгүй тэмдэглэл `session-report.md` файлд, согог бүрийн дахин гаргах алхам `bugs/` хавтсанд хадгалагдсан.
