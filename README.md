**Browser:** Google Chrome (version to be verified)

## Зорилго

Уншлагын жагсаалт вэб аппликейшнд Session-Based Test Management (SBTM) аргаар exploratory тест хийж, тестийн charter, session report болон илэрсэн согогийн тайлангуудыг боловсруулах.

## Файлын бүтэц

- `charter.md` — тестийн зорилго, сонгосон аяллууд
- `session-report.md` — 60 минутын session тэмдэглэл
- `bugs/` — согогийн тайлангууд
- `screenshots/` — UI согогийн screenshot
- `evidence/` — API тестийн нотолгоо

## Дүгнэлт

Энэ хэсгийг exploratory testing session дууссаны дараа бодит үр дүнд үндэслэн бөглөнө.
