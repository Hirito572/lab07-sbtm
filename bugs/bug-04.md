# BUG-04: API буруу JSON оролтыг зөвшөөрч байна

**Орчин:** Уншлагын жагсаалт v2.0, macOS, 2026-10-21

**Урьдчилсан нөхцөл:** `node app.js` ажиллаж, `localhost:3000` хаяг дээр API боломжтой байна.

## Дахин гаргах алхам

1. Terminal нээнэ.
2. Дараах командыг ажиллуулна:

   `curl -i -X POST http://localhost:3000/api/books -H 'Content-Type: application/json' -d 'буруу оролт'`

**Хүлээгдэж байсан:** Буруу JSON хүсэлтэд HTTP 400 хариу буцаана.

**Бодит үр дүн:** API `HTTP/1.1 200 OK` болон `{"result":"OK"}` буцаасан.

**Ноцтой байдал:** Major — API буруу форматтай хүсэлтийг амжилттай мэт хүлээн авч байна.

**Хавсралт:** `evidence/bug-04-curl.txt`

**Олдсон аялал:** Saboteur — API түвшний буруу оролтын шалгалт.
